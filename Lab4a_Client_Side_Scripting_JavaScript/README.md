## Introduction

This laboratory exercise focuses on client-side scripting using HTML5 and modern JavaScript.

The objective is to develop interactive webpages using JavaScript functions, event handling, conditional statements, input validation, loops and DOM manipulation.

## Question 1 - Interactive Text Changer

This webpage uses JavaScript DOM selection methods, functions and event listeners to change a paragraph when the user clicks the Change Message button.

**How to run:**
1. Open the `Q1_Interactive_Text_Changer` folder.
2. Open `index.html` using Google Chrome.
3. Click the **Change Message** button.
4. The paragraph will change to "Hello there!".

## Question 2 - Smart Number Validator

This webpage accepts a number from the user and validates the input using `Number()`, `if...else if...else` statements and `textContent`.

**How to run:**
1. Open the `Q2_Smart_Number_Validator` folder.
2. Open `index.html` using Google Chrome.
3. Enter a number in the input field.
4. Click **Check** to display the validation message.

## Question 3 - Dynamic Number Generator

This webpage dynamically generates an ordered list from 1 to 5 using a `for` loop and DOM manipulation.

**How to run:**
1. Open the `Q3_Dynamic_Number_Generator` folder.
2. Open `index.html` using Google Chrome.
3. Click **Generate** to display the five list items.
